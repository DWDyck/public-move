# PUBLIC / MOVE

A working concept from 2040: **public transportation reimagined around self-driving vehicles**, run as one public network, built for public benefit, not profit.

**Live demo:** https://dwdike-maker.github.io/public-move/

## The idea

Government-owned autonomous cars, shared shuttles, mass transit, emergency units and neighbours' contributed cars operate as a single network with:

- A **Mobility Guarantee**: maximum pickup times, 24/7 essential service, accessible vehicles, guaranteed return trips
- **Open costs**: fares cover energy and upkeep only, with a monthly cap. No surge pricing, tips, ads, premium tiers or queue-jumping
- **Accessibility first**: wheelchair, no-stairs, quiet cabin, audio navigation, larger text, reduced motion
- **Community Service**: residents can lend a parked car and be reimbursed for energy
- **Honest trade-offs**: drivers' livelihoods, privacy, safety evidence and funding are named as open questions

The goal is to show how valuable self-driving technology could be for public transit, and to argue that mobility should be a public right.

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Notes

Everything is simulated. There are no real vehicles, accounts, payments or dispatch, and city statistics are fictional. Real-world figures (AAA, APTA, NHTSA, EPA, ITF/OECD, CDC) are rounded and credited in-app; check the originals before citing.
